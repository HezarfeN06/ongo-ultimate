# Güvenlik bildirimi

Güvenlik sorunlarının ayrıntılarını herkese açık issue veya discussion içine göndermeyin.

1. [Destek merkezinden](https://kayit.ongo.com.tr/hesabim/destek) özel talep açın.
2. Sürümü, etkilenen alanı, tekrar üretme adımlarını ve beklenen/gerçek davranışı açıklayın.
3. Parola, sağlayıcı API anahtarı, lisans kodu, config.php veya gerçek müşteri verisi paylaşmayın. Kayıtları önce maskeleyin.

Bu depo her hosting ortamında sıfır hata veya sıfır açık garantisi sunmaz. Üçüncü taraf hesaplarınızın ve hosting ortamınızın güncelliğini ayrıca takip edin.
